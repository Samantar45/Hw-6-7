# Tetris Game 🎮  
A fully functional Tetris clone built using **HTML, CSS, and JavaScript (Canvas API)**.  
Includes modern features such as hold piece, next preview, hard drop, high-score persistence, and full mobile controls.

## ✨ Features
- Classic falling block gameplay  
- Rotations, soft drop, hard drop  
- Hold piece system  
- Next-piece preview

- Automatic increasing difficulty  
- Mobile-friendly controls  
- LocalStorage high-score saving

## ▶ How to Play

### Desktop Controls
- **← / →** — Move  
- **↓** — Soft drop  
- **↑** — Rotate  
- **Space** — Hard drop  
- **C** — Hold piece  
- **P** — Pause  
- **R** — Restart  

### Mobile Controls
Large buttons for:
- Move left/right  
- Rotate  
- Soft drop  
- Hard drop  
- Hold
